Install with the wizard

Install the isolated Python application, then let one guided flow create a separate private vault and preview its bounded operating policy.

Python 3.11+ Release line: 2.1.0 Source candidate: 2.1.1rc1, unreleased

1. Install exact 2.1.0

pipx is the recommended path because it isolates Python applications while exposing their commands on your path. The exact pin prevents a silent downgrade to an older package.

pipx install ai-dememory==2.1.0

Equivalent with uv:

uv tool install ai-dememory==2.1.0

Installation is passive. It does not create a vault, scan provider folders, install hooks or scheduled jobs, or start a model.

2. Use the published 2.1.0 wizard

The vault is your data boundary. Put it somewhere separate from the public tool repository and keep that location private. Published 2.1.0 creates the template, previews the operational policy, shows the limits and fingerprint, and asks once before writing .ai-dememory.toml.

ai-dememory init ~/code/my-memory --wizard --require-version 2.1.0

On Windows, a path such as D:\Memory\my-vault works too. The trailing exact-version gate is a 2.1.0 compatibility detail, not a separate diagnostic step. The wizard is configuration-only: it does not import chats, create durable personal memories, install hooks or schedules, start a model, or edit a client configuration.

  • Markdown remains canonical and human-editable.
  • The SQLite full-text index is generated and rebuildable.
  • Public demo fixtures stay in the source repository; personal memory does not.

3. Source candidate 2.1.1rc1: the simplified wizard

Source candidate 2.1.1rc1 is unreleased and not installable from a package index until it is tagged and published. It removes the persistent compatibility pin from new setup and generated configuration; it does not loosen vault binding, profiles, allowlists, or idle leases.

ai-dememory init ~/code/my-memory --wizard

This is a behavior preview, not a package-install command. A tagged, published artifact and post-index verification are separate release steps.

4. Choose a bounded candidate intensity

The candidate wizard asks for an intensity. It controls local work and context envelopes, not a language model, and is not a promise of fixed machine cost.

Built-in operating profiles
Profile Recall Cadence after explicit setup Candidates File / scan ceilings
minimal Manual only Weekly 5 / run 32 KiB / 500
balanced recommended Up to 1,200 tokens Daily + weekly 20 / run 64 KiB / 2,500
active Up to 2,400 tokens Daily + weekly 50 / run 128 KiB / 10,000

Balanced is recommended for a first candidate installation. Every configurable resource still sits inside absolute minimum and maximum limits.

Model policy is separate

  • off — deterministic local tools only.
  • advisory — an already active host agent may triage and recommend.
  • proposals — that host agent may prepare review-first inbox proposals.

ai DeMemory itself makes zero model and embedding calls in every profile. A host agent can still consume its normal model tokens when advisory or proposal work is enabled.

5. Connect an AI client (optional)

Generate vault-bound configuration only when you are ready to connect Codex, Claude, or another client. Inspect it before copying it into the host configuration. The wizard stops here because it cannot safely choose or edit a host application's settings on your behalf.

ai-dememory --root ~/code/my-memory mcp-config --client codex

In published 2.1.0, the generated runtime configuration persists the historical exact-version pin; the candidate removes that generated pin. Both bind the vault, make core the reduced four-tool server-enforced default, and use a 600-second idle lease so an abandoned MCP process exits. Explicit admin preserves the complete historical MCP surface for compatibility and broad maintenance; it is not the recommended default.

See the process lifecycle or read the full MCP guide on GitHub.

6. Update or diagnose a stable installation

Repair an existing pipx installation with the same immutable package pin. Use the normal version output when diagnosing a PATH or package issue.

pipx install --force ai-dememory==2.1.0
ai-dememory --version

The version-check subcommand remains an exact diagnostic for CI and support work; it is not a prerequisite for installation or the wizard. Once you add Markdown to a vault, run ai-dememory --root ~/code/my-memory index to rebuild its disposable search index.
