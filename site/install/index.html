Install in five minutes

Install the isolated Python application, create a separate private vault, then inspect the setup plan before enabling anything autonomous.

Python 3.11+ Release line: 2.1.0 Source/release line: 2.1.0
On this page Install exact 2.1.0 Create a private vault Upgrade to 2.1.0 Choose an intensity Review the wizard Connect a client

1. Install exact 2.1.0

pipx is the recommended path because it isolates Python applications while exposing their commands on your path. The exact pin fails instead of silently selecting an older release when 2.1.0 is not yet available.

pipx install ai-dememory==2.1.0
ai-dememory version-check 2.1.0

Equivalent with uv:

uv tool install ai-dememory==2.1.0
ai-dememory version-check 2.1.0

Installation is passive. It does not create a vault, scan provider folders, install hooks or scheduled jobs, or start a model.

2. Create and verify a private vault

The vault is your data boundary. Put it somewhere separate from the public tool repository and keep that location private.

ai-dememory init ~/code/my-memory
cd ~/code/my-memory
ai-dememory doctor
ai-dememory index
ai-dememory graph
ai-dememory setup plan --require-version 2.1.0 --json
ai-dememory setup health --json

On Windows, a path such as D:\Memory\my-vault works too. Run the remaining commands from inside that vault.

  • Markdown remains canonical and human-editable.
  • The SQLite full-text index is generated and rebuildable.
  • Public demo fixtures stay in the source repository; personal memory does not.

3. Replace or repair with exact 2.1.0

Upgrade a normal PyPI installation, verify the selected version, then regenerate and smoke-test every vault-bound MCP fragment.

pipx install --force ai-dememory==2.1.0
ai-dememory version-check 2.1.0
cd ~/code/my-memory
ai-dememory mcp-config --client codex --require-version 2.1.0
ai-dememory mcp-client-smoke

Use the exact pipx install --force ai-dememory==2.1.0 command above to repair an environment that already tracks PyPI. If it came from a release candidate or mutable Git checkout, rebuild it against the immutable stable artifact:

pipx uninstall ai-dememory
pipx install ai-dememory==2.1.0
ai-dememory version-check 2.1.0

Inspect the generated MCP output and replace the prior host entry yourself. The command does not silently edit Codex, Claude, or another client, and the emitted server command repeats the exact-version gate so a stale Docker image fails before serving MCP.

4. Choose a bounded intensity

Intensity controls local work and context envelopes. It does not select a language model and is not a promise of fixed machine cost.

Built-in operating profiles
Profile Recall Cadence after explicit setup Candidates File / scan ceilings
minimal Manual only Weekly 5 / run 32 KiB / 500
balanced recommended Up to 1,200 tokens Daily + weekly 20 / run 64 KiB / 2,500
active Up to 2,400 tokens Daily + weekly 50 / run 128 KiB / 10,000

Balanced is recommended for a first verified 2.1.0 installation. Every configurable resource still sits inside absolute minimum and maximum limits.

Model policy is separate

  • off — deterministic local tools only.
  • advisory — an already active host agent may triage and recommend.
  • proposals — that host agent may prepare review-first inbox proposals.

ai DeMemory itself makes zero model and embedding calls in every profile. A host agent can still consume its normal model tokens when advisory or proposal work is enabled.

5. Review and confirm the setup wizard

Start with a machine-readable plan, then use the interactive wizard. It exposes the config-only operating policy, caps, planned file, and an exact fingerprint before asking once whether to apply that same in-memory plan.

ai-dememory setup plan \
  --require-version 2.1.0 \
  --intensity balanced \
  --model-policy off --json
ai-dememory setup wizard --require-version 2.1.0
ai-dememory setup health --json
# Optional, separate reviewed personal memory
ai-dememory onboard

Answering no writes nothing and reports that setup is incomplete. setup wizard --require-version 2.1.0 --json previews safe operational defaults without prompting. Personal values and project profiles belong only to the optional ai-dememory onboard flow. Both machine-readable contracts stay passive: apply still requires the exact preview fingerprint via --expect-plan-sha256, and changed input requires a fresh preview.

The wizard applies only .ai-dememory.toml. It does not create personal memory or install MCP configuration, hooks, provider imports, or scheduler jobs. Each remains a separate, inspectable step.

6. Connect an AI client

Generate vault-bound configuration from inside your vault, inspect it, and smoke-test the installed client path.

ai-dememory version-check 2.1.0
ai-dememory mcp-config --client codex --require-version 2.1.0
ai-dememory mcp-client-smoke

The verified 2.1.0 executable makes core the reduced four-tool, server-enforced default, requires the bound vault, repeats the 2.1.0 runtime gate, and generates a 600-second balanced idle lease so an abandoned MCP process exits. Explicit admin preserves the complete historical MCP surface for compatibility and broad maintenance; it is not the recommended default.
