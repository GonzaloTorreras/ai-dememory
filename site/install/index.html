Install with the wizard

ai-dememory 2.1.1 is the current stable PyPI release. Install the package, then use the wizard to create a separate private vault.

1. Install ai-dememory

pipx is the recommended path because it isolates Python applications while exposing their commands on your path.

pipx install ai-dememory

Equivalent with uv:

uv tool install ai-dememory

Installation is passive. It does not create a vault, scan provider folders, install hooks or scheduled jobs, or start a model.

2. Use the wizard

The vault is your data boundary. Put it somewhere separate from the public tool repository and keep that location private. The wizard creates the template, previews the operational policy, shows the limits and fingerprint, and asks once before writing .ai-dememory.toml.

ai-dememory init ~/code/my-memory --wizard

On Windows, a path such as D:\Memory\my-vault works too. The wizard is configuration-only: it does not import chats, create durable personal memories, install hooks or schedules, start a model, or edit a client configuration.

  • Markdown remains canonical and human-editable.
  • The SQLite full-text index is generated and rebuildable.
  • Public demo fixtures stay in the source repository; personal memory does not.

3. Choose a bounded intensity

The wizard asks for an intensity. It controls local work and context envelopes, not a language model, and is not a promise of fixed machine cost.

Built-in operating profiles
Profile Recall Cadence after explicit setup Candidates File / scan ceilings
minimal Manual only Weekly 5 / run 32 KiB / 500
balanced recommended Up to 1,200 tokens Daily + weekly 20 / run 64 KiB / 2,500
active Up to 2,400 tokens Daily + weekly 50 / run 128 KiB / 10,000

Balanced is recommended for a first installation. Every configurable resource still sits inside absolute minimum and maximum limits.

Model policy is separate

  • off — deterministic local tools only.
  • advisory — an already active host agent may triage and recommend.
  • proposals — that host agent may prepare review-first inbox proposals.

ai DeMemory itself makes zero model and embedding calls in every profile. A host agent can still consume its normal model tokens when advisory or proposal work is enabled.

4. Connect an AI client (optional)

Generate vault-bound configuration only when you are ready to connect Codex, Claude, or another client. Inspect it before copying it into the host configuration. The wizard stops here because it cannot safely choose or edit a host application's settings on your behalf.

ai-dememory --root ~/code/my-memory mcp-config --client codex

The generated runtime configuration binds the vault, makes core the reduced four-tool server-enforced default, and uses a 600-second idle lease so an abandoned MCP process exits. Explicit admin preserves the complete historical MCP surface for compatibility and broad maintenance; it is not the recommended default.

If a local dashboard or script needs HTTP instead of MCP stdio, the optional API runs only when you start it. Read the canonical Local API guide for the loopback-only default and network-binding safeguards.

See the process lifecycle or read the full MCP guide on GitHub.

5. Update or diagnose the installation

Repair an existing pipx installation with the current stable package. Use the normal version output when diagnosing a PATH or package issue.

pipx install --force ai-dememory
ai-dememory --version

Once you add Markdown to a vault, run ai-dememory --root ~/code/my-memory index to rebuild its disposable search index.
